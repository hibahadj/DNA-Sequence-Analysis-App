# DNA Sequence Analysis App

Tkinter GUI app for DNA sequence analysis and mutation detection (mini-project).

## Run

From the repo root:

- Windows (venv python): `python app.py`

## Embedded 3D (optional)

The Visualization tab can open Mol* inside an embedded window (still part of the app).

- Install: `pip install pywebview`
- Then click **Open embedded 3D**

## Inputs

- Paste FASTA text or raw DNA.
- Or load FASTA files using the buttons.

Example FASTA files are in `examples/`.
